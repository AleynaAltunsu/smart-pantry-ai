# Model ağırlıkları

`.pt` dosyaları (YOLO-World) boyut nedeniyle repoya konmaz. `pip install -r requirements-cv.txt`
sonrası ilk açılışta ultralytics `yolov8m-worldv2.pt` / `yolov8s-world.pt` dosyalarını otomatik indirir.
Elle koymak istersen dosyaları bu klasöre kopyala; uygulama önce buraya bakar.
Başka model için: `SMART_PANTRY_YOLO_MODEL=yolov8l-worldv2.pt`.
